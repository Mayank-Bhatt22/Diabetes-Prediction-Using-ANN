# Diabetes-Prediction-Using-ANN
A Deep Learning project that predicts the likelihood of diabetes using an Artificial Neural Network (ANN). The project includes data preprocessing, feature scaling, model building, training, and performance evaluation using Python, TensorFlow, and Keras.

# 🩺 Diabetes Prediction Using ANN

This project uses an **Artificial Neural Network (ANN)** to predict the likelihood of diabetes based on different health and medical-related features.

The project is part of my **Deep Learning learning journey at DUCAT**. I worked through the project step by step and implemented the code myself, with guidance from my teacher to better understand the concepts and workflow.

## 📌 Project Overview

The main goal of this project is to build and train an Artificial Neural Network that can analyze patient data and predict the likelihood of diabetes.

The project covers the complete Deep Learning workflow, including:

- Data loading
- Data exploration
- Data preprocessing
- Handling categorical data
- Feature scaling
- Train-test split
- Building an ANN model
- Model training
- Making predictions
- Model evaluation

## 🧠 What is ANN?

An **Artificial Neural Network (ANN)** is a Deep Learning model inspired by the structure of the human brain. It consists of connected layers of neurons that learn patterns from data and use those patterns to make predictions.

## 🛠️ Technologies Used

## ⚙️ Project Workflow

1. Load the diabetes dataset.
2. Explore and understand the data.
3. Preprocess the dataset.
4. Encode categorical features if required.
5. Scale the numerical features.
6. Split the data into training and testing sets.
7. Build an Artificial Neural Network.
8. Train the model using the training data.
9. Make predictions on the test data.
10. Evaluate the model's performance.

## 🧱 ANN Model

The model is built using TensorFlow and Keras with:

- Input Layer
- Hidden Layers
- Activation Functions
- Output Layer
- Optimizer
- Loss Function
